# 分析方法

## 顺序

1. 先核对粒度、主键、时间字段、单位和缺失值编码。
2. 再检查重复行、类型混合、极端值、无变化列和类别基数。
3. 先做描述统计和可视化，再决定是否需要分组比较、相关性或趋势分析。
4. 只有数据设计支持时才讨论因果；否则使用“相关”“同时变化”“样本中观察到”等措辞。

## 质量阈值

- 缺失率大于 20%：高风险，解释任何统计前先说明。
- 唯一值等于行数：可能是主键，不应直接作为类别作图。
- 数值列有效值少于 5：不报告稳定分布结论。
- 数据被截断：结论仅代表已分析样本，不能冒充全量结果。

## 交付检查

- 报告中的数字必须能在 profile 或输出表中追溯。
- 清洗动作必须可逆或在报告中逐项记录。
- 图表要有标题、指标、单位和样本范围。
- 保留可复现脚本，不把模型猜测写进确定性计算结果。
