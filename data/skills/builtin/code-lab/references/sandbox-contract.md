# 沙盒约定

## 路径

- 主代码由运行器创建，不需要自行写入。
- 输入附件只读挂载在 `/workspace/input`。
- 交付文件必须写入 `/workspace/output`。
- `/tmp` 可写但不会被保存。免费版为 256 MiB，普通有效订阅为 512 MiB，Family Pass 为 1 GiB。

## 安全边界

- runtime 固定为 Docker `runsc`，缺失时拒绝执行。
- 网络、IPC、Linux capabilities 和提权均关闭。
- 根文件系统和代码目录只读，以非 root 用户运行。
- CPU、内存、PID、运行时间、标准输出和文件输出均有限额。
- 每次运行使用独立临时目录，结束后强制销毁容器和目录。
- 普通 `run_code` 最长 120 秒；超过 120 秒的任务进入可刷新恢复、可停止的后台 Code Lab，最长 300 秒。

## 结果判断

- `exitCode = 0` 表示程序正常退出，不等于业务结论必然正确。
- 非零退出码和 stderr 应作为调试证据保留。
- `timedOut`、标准输出超限或文件输出超限必须在最终回复中说明。
- 只有工具返回的 `attachments` 才能作为已生成文件交付。
